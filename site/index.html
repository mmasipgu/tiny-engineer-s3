Antes de instalar: desconecta mecánicamente los servos o asegúrate de que pueden moverse con seguridad. El montaje usa PCA9685 en GPIO8/9, OE en GPIO16 y MAX98357A en GPIO17/18/21.
  1. Conecta el ESP32-S3 al ordenador mediante un cable USB de datos.
  2. Usa Chrome o Microsoft Edge.
  3. Pulsa Instalar firmware y selecciona el puerto del ESP32-S3.
  4. Cuando termine, reinicia la placa.
  5. Al reiniciar, únete a la Wi‑Fi TinyEngineer-XXXX y abre http://192.168.4.1/config.
Tu navegador no soporta Web Serial. Usa Chrome o Microsoft Edge en un ordenador. El instalador necesita HTTPS (o localhost).
Este instalador borra/reemplaza el firmware del ESP32 conectado. Está preparado exclusivamente para ESP32-S3-N16R8.
